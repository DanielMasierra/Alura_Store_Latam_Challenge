# Análisis de desempeño – Alura Store
## Descripción del proyecto
Este proyecto corresponde al Challenge 1 de Data Science de Alura LATAM. El objetivo es analizar el desempeño de las cuatro tiendas de Alura Store para recomendar cuál debería vender el Sr. Juan con el fin de iniciar un nuevo emprendimiento, utilizando datos de ventas y métricas clave de rendimiento.
## Objetivo del análisis
Identificar la tienda menos eficiente a partir de un análisis comparativo basado en ingresos, comportamiento de ventas y percepción del cliente.
## Tecnologías utilizadas
Python 3  
Pandas  
Matplotlib  
Google Colab
## Estructura del proyecto
├── notebook.ipynb  
├── README.md
## Análisis realizado
Se analizaron los ingresos totales por tienda, la distribución de categorías de productos, la calificación promedio de los clientes, los productos más y menos vendidos y el costo promedio de envío. A partir de estos datos se generaron distintos tipos de gráficos para facilitar la interpretación de los resultados.
## Conclusión
Con base en el análisis realizado, se recomienda vender la tienda_4, ya que presenta el menor ingreso total en comparación con las demás tiendas. Aunque cuenta con un costo de envío promedio más bajo y una calificación aceptable por parte de los clientes, su desempeño global es inferior, por lo que venderla representa el menor costo de oportunidad para el negocio.
